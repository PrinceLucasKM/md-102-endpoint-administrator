### Day 1 — Prepare infrastructure & manage devices
- Plan and implement device enrollment (Intune)
- Windows Autopilot (deployment profiles, modes, device name templates)
- Microsoft Entra ID join & registration
- Device configuration profiles (Windows, Android, iOS/iPadOS, macOS, specialty devices)
- Windows updates, Autopatch, update rings
- Enrollment profiles & troubleshooting

### Day 2 — Manage applications & protect devices
- Enterprise App Catalog & M365 Apps deployment
- App protection policies (managed / BYOD)
- Microsoft Entra Conditional Access
- BitLocker, Windows Hello for Business, Windows LAPS
- Microsoft Defender for Endpoint integration
- Microsoft Tunnel, Cloud PKI, compliance policies
- Attack surface reduction & App Control for Business

### Day 3 — Automate & operational excellence
- PowerShell & Microsoft Graph automation
- Security Copilot agents in Intune
- Role-based access & multi-admin approval
- Endpoint Analytics, proactive remediation
- Tenant health, alerts & compliance drift monitoring

### Day 4 — Intune Suite & cloud desktops
- Endpoint Privilege Management (EPM)
- Remote Help, Advanced Analytics
- Azure Virtual Desktop & Windows 365 provisioning
- Enrollment Status Page (ESP)
- Device diagnostics, KQL queries, bulk remote actions
